# 🎓 Student Result Analyzer

A simple and user-friendly Student Result Analyzer built using Python and Streamlit.

The application allows users to enter student information and subject marks. It automatically calculates the total marks, percentage, grade, and pass/fail result.

## 🚀 Features

- Student name and roll number input
- Marks entry for multiple subjects
- Automatic total marks calculation
- Percentage calculation
- Automatic grade calculation
- Pass/Fail evaluation
- Result table
- CSV result download
- Simple and interactive web interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
